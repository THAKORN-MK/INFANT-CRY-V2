# User-managed dataset

The folder suffix `_v2` is this project's internal model-generation label; the current source files are Mendeley InfantCry-DBL V1 (dataset version 1.0). The copied audio is under `data/raw/infantcry_dbl_v2/`; preserve its archive's folder layout and metadata. Do not add the audio to Git. The current copy has a corrected audit and locked split under `manifests/model_v2_dataset_v1/` and `manifests/splits/model_v2_dataset_v1/`. If replacing or recopying data, treat it as a new source copy and rerun audit and split before training.
